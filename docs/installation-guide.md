# TIANLANG Lightbox - Installation Guide

## SEG Lightbox Installation

### Tools Required
- None! (Tool-free assembly)

### Step 1: Frame Assembly
1. Unpack all aluminum frame components
2. Connect corner connectors to frame sections
3. Ensure all corners are properly aligned at 90°
4. Tighten all connections securely

### Step 2: LED Installation
1. Unroll the LED strip kit
2. Attach LED strips to the designated channels inside the frame
3. Connect the power supply to the LED strips
4. Test the lighting before proceeding

### Step 3: Graphic Installation
1. Unroll the SEG graphic (sublimation printed fabric)
2. Starting from one corner, insert the silicone edge into the frame channel
3. Work your way around the frame, stretching the graphic evenly
4. Ensure the graphic is taut and wrinkle-free
5. Tuck any excess fabric into the channel

### Step 4: Mounting
**Wall Mount:**
1. Mark mounting hole positions on the wall
2. Install wall anchors and screws
3. Hang the lightbox on the wall mounts
4. Secure with locking screws

**Freestanding:**
1. Attach the base/stand to the lightbox frame
2. Ensure the stand is level and stable
3. Position in the desired location

**Suspended/Hanging:**
1. Install ceiling mounting points
2. Attach cables/wires to the lightbox
3. Adjust height using cable adjusters
4. Ensure level alignment


## Modular Booth Installation

### Step 1: Layout Planning
1. Review the booth floor plan
2. Mark the booth area on the exhibition floor
3. Organize all components by section

### Step 2: Frame Assembly
1. Connect aluminum frame sections using the plug-in connectors
2. Build the backwall structure first
3. Add side walls and overhead structures
4. Ensure all connections are secure

### Step 3: Panel Installation
1. Attach fabric panels to the frame using the tension system
2. Start from the center and work outward
3. Ensure panels are taut and properly aligned
4. Install SEG lightbox panels in designated positions

### Step 4: Lighting Installation
1. Connect all LED lighting components
2. Test each lightbox section individually
3. Ensure uniform illumination across all panels

### Step 5: Furniture Setup
1. Assemble counters, tables, and display units
2. Position furniture according to the floor plan
3. Secure any loose components

### Step 6: Final Check
1. Verify all graphics are properly installed
2. Test all lighting
3. Check stability of all structures
4. Make any final adjustments

## Troubleshooting

### Light Not Working
1. Check power supply connection
2. Verify power outlet is working
3. Check LED strip connections
4. Replace fuse if necessary

### Uneven Lighting
1. Check LED strip alignment
2. Verify all LED segments are connected
3. Check for loose connections

### Graphic Wrinkles
1. Re-insert the graphic, starting from the center
2. Stretch the fabric evenly around the frame
3. Ensure the silicone edge is fully seated in the channel

### Frame Not Level
1. Adjust mounting points
2. Use shims if necessary
3. Check floor level for freestanding units


## Maintenance Tips

### Daily
- Wipe surfaces with a soft, dry cloth
- Check for any loose connections

### Weekly
- Clean LED diffusers with a soft cloth
- Inspect graphic for any damage
- Verify all lights are working

### Monthly
- Check all electrical connections
- Clean ventilation areas
- Inspect frame for any damage

### Annually
- Replace LED strips if brightness has decreased
- Check all mounting hardware
- Professional inspection recommended for large installations
