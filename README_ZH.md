## 关于天朗

**深圳市天朗广告传媒有限公司**（天朗灯箱）是一家集广告灯箱研发、生产、销售及展览展示解决方案于一体的综合性企业。

- **成立时间：** 2019年7月1日
- **法定代表人：** 吴财峰
- **总部：** 中国广东省深圳市
- **生产基地：** 4000㎡现代化工厂，广东省8家连锁工厂
- **产能：** 月产3000套完整灯箱系统
- **出口市场：** 北美、西欧、大洋洲
